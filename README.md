# Mapa de Prova

Mapa de sala para **aplicação de provas**: advertências, chamada, entregas, banheiro, cronômetro e relatório — tudo num único `index.html`, sem instalar nada. Funciona no celular, tablet e computador, e os dados ficam salvos no próprio navegador.

## Como usar

1. Abra o `index.html` (ou publique no GitHub Pages).
2. Monte a sala em **Organizar → Grade** e cole a lista de alunos em **Alunos → Importar e sortear**.
3. Escolha um **modo** na barra de baixo e toque nas cadeiras:

| Modo | Toque na cadeira |
|---|---|
| **Ver** | abre os detalhes · 2 toques = advertência · segurar = mover |
| **Advertir** | +1 advertência (com o motivo escolhido: conversa, celular, cola…) |
| **Presença** | marca ausente / presente |
| **Entrega** | registra a entrega com horário |
| **Banheiro** | sai, entra na fila ou volta |
| **Organizar** | arrastar cadeiras, adicionar, numerar, girar |

Todo toque pode ser desfeito (botão no aviso ou `Ctrl+Z`).

## Recursos

- **Advertências com motivo e horário**, cor da cadeira conforme a gravidade e aviso ao atingir o limite (com opção de recolher a prova).
- **Banheiro** com fila, cronômetro, limite de tempo, alerta e histórico.
- **Cronômetro da prova** com avisos de 30/15/5/1 min, tempo mínimo para sair e **telão** em tela cheia para projetar.
- **Lista de alunos**: cole do Excel/Sheets; distribui **intercalando turmas** para evitar cola (a lente de turmas mostra vizinhos da mesma turma).
- **Trocar aluno de lugar** levando advertências e situação junto.
- **Várias salas**, duplicar layout, “nova aplicação” (zera a sessão mantendo os alunos).
- **Relatório/ata** com mapa da sala: copiar para WhatsApp, imprimir/PDF ou planilha CSV.
- Ocorrências livres, busca em todas as salas, modo escuro, atalhos de teclado (`?`), tela sempre ligada durante a prova.
- **Backup** em JSON (importa também os backups da versão antiga). Os dados da versão antiga salvos no mesmo navegador são trazidos automaticamente.
